# Codsoft
🔗 Task 1 – Personal Portfolio 

This project is a personal portfolio website built using HTML and CSS. It displays information about me, my skills, projects, resume, and contact details. The website is fully responsive and designed to showcase my profile professionally.

🔗 Task 2 - Landing Page 

involves designing a simple and visually appealing landing page using HTML and CSS. The project helps in understanding webpage structure, section division, alignment, padding, color combinations, and the use of headers and footers. It encourages creativity while ensuring a clean, user-friendly, and well-organized layout.

🔗 Task 3 - Calculator (Description)

focuses on creating a basic calculator using HTML, CSS, and JavaScript with an interactive user interface. The calculator performs arithmetic operations like addition, subtraction, multiplication, and division using event handling and conditional logic. This project strengthens understanding of CSS Grid for layout and JavaScript for handling user input and calculations.
