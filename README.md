# Codsoft
✅ LEVEL 1 – Personal Portfolio  This project is a personal portfolio website built using HTML and CSS. It displays information about me, my skills, projects, resume, and contact details. The website is fully responsive and designed to showcase my profile professionally.

✅ LEVEL 2 – Online Quiz Maker
This project is an online quiz application developed using HTML, CSS, and JavaScript.
Users can create quizzes, answer multiple-choice questions, and receive instant score feedback.
The application is responsive and provides an interactive learning experience.

✅ LEVEL 3 – Project Management Tool
This project is a full-stack project management tool developed using React, Node.js, and MongoDB.
It allows users to create projects, assign tasks, set deadlines, and track progress.
The system supports user authentication and is deployed using a free hosting platform.
